# Implementation contract

## First executable slice

Before bulk expansion, one browser action must traverse the checked TypeScript client, `/api/v1`, every registered middleware class, `cr-application`, meaningful domain behavior, the selected upstream boundaries, an authorized OpenDAL write/read, and a rendered result. A mocked first-party API, static preview, or CLI output does not satisfy this milestone.

## Backend obligations

- `cr-service` is the launched default binary and only composition root.
- At least 20 of the 29 production-reachable packages remain independently substantive under semantic review; the final count is 22, with seven common evidence-book support packages excluded.
- Cargo metadata is recorded with exactly `cargo metadata --locked --offline --format-version 1`; stdout and stderr are separate recorder artifacts.
- Every counted crate is reachable through production dependencies and has a real caller, behavior test, and failure test.
- Every selected upstream has an application call site and source-bound success and substantive failure evidence.
- Cedar denial occurs before intervention and persistence effects; storage failure cannot return success.

## API and frontend obligations

- OpenAPI schema version `v1`, checked/generated TypeScript client, and drift test are committed.
- Middleware registers correlation, observability, timeouts, authn, authz, validation, policy, and errors in the documented order.
- React supplies Habitat Map, Sensor Trust, Anomaly Workbench, Intervention Planner, Offline Mesh, and Audit Vault views with loading, error, success, denial/recovery, and restart-retrieval states.
- Desktop and mobile Playwright journeys use the real frontend and backend.

## Delivery and evidence

Dependencies and toolchains are locked. `.env.example` contains no secrets or sensitive locations. Start, stop, reset, readiness, deterministic seed, containers, and one launch command are required. Cloud Run and rollback files are configuration only. `verify-prototype.sh` must launch the stack and execute the complete contract in CI.

External schema-v2 evidence binds the clean candidate and includes recorder logs, backend metadata, composition report schema 2, semantic review, browser JSON/trace/screenshots, correlation trace, benchmark, ablations, containers, selection report schema 1, probe archive, and gate outputs. Until read back, verdicts remain **PENDING**.
